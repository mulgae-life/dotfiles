# start

새 세션 시작 시 문서로 맥락을, 코드로 실체를 파악한 뒤 현재 상태와 다음 작업을 요약합니다. 문서만 읽고 코드를 모른 채 작업에 들어가지 않습니다.

**범위**: 읽고 요약하는 것까지입니다. 문서에 적힌 상태를 실측으로 검증하거나(프로세스·데이터·실행 결과 확인), 작업에 착수하거나, 파일을 고치지 않습니다. 그런 일은 요약을 보고 사용자가 지시합니다. 단 "파악한 다음 X를 해줘"처럼 후속 작업을 이미 함께 요청받았으면 요약 뒤 재승인 없이 그 작업으로 이어갑니다.

**경로**: 아래 경로는 모두 프로젝트 루트 기준입니다. 하위 디렉토리에서 시작했으면 루트를 먼저 찾습니다.

**세 단계를 모두 수행합니다.** 다음 작업이 코드 작업이 아니거나 대기 구간이어도 2단계를 건너뛰지 않습니다. 목적은 이번 세션의 첫 작업이 아니라 프로젝트를 아는 것입니다.

## 1단계: 문서 읽기

1. `agent-guide/GUIDE.md` → 작업 원칙·용어·협업 규칙
2. `agent-guide/PROJECT.md` → 구조, 기술 스택, 코드 지도
3. `agent-guide/SESSION.md` → 현재 상태와 **다음 작업** (2단계에서 읽을 영역을 정하는 기준). 길면 "다음 작업"과 최근 상태 절을 읽고 이력 절은 제목만 훑습니다
4. 도구·프로젝트 지침이 정한 교훈 파일(auto memory `lessons_*.md`, `.codex/lessons.md` 등)이 있으면 읽고 반영. 알려진 경로가 없으면 생략

`agent-guide/`가 없으면 `README.md`와 프로젝트 경로의 참조할 만한 문서를 읽고 같은 절차를 따릅니다.

## 2단계: 코드 읽기

핵심 코드는 두 등급으로 나눠 읽습니다. 전부 읽지 않습니다.

| 등급 | 무엇 | 언제 |
|------|------|------|
| **골격** | 진입점, 설정 정의, 메인 루프·오케스트레이션 등 실행 흐름을 이루는 파일 | 항상 |
| **영역** | 도메인 모듈 (라우트, 서비스, 스토어, 도메인 모델 등 기능 단위) | SESSION.md의 다음 작업과 관련된 영역만 |

### 2-1. PROJECT.md에 코드 지도가 있으면

- "코드 지도" 표에서 등급이 골격인 파일을 전부 읽습니다
- 다음 작업이 속한 영역의 파일을 읽습니다. 관련 없는 영역은 건너뜁니다
- 표에 적힌 파일이 없거나, 골격에 해당하는데 표에 없는 파일이 보이면 3단계 출력에서 **문서·코드 불일치**로 보고합니다 (보고까지만 하고 문서를 고치지는 않습니다)

### 2-2. 코드 지도가 없으면 (직접 탐색)

1. 진입점 찾기 — PROJECT.md의 "빠른 시작" 명령이나 `README.md`의 실행 명령이 가리키는 모듈·스크립트, 패키지 매니페스트의 `main`·`scripts`·엔트리 정의
2. 진입점에서 import·호출 사슬을 2단계까지 따라가며 골격 파일을 정합니다
3. 다음 작업에서 언급된 모듈·디렉토리를 영역 파일로 정합니다
4. 읽은 목록을 3단계 출력에 표로 남기고, PROJECT.md 코드 지도로 등재할지 사용자에게 제안합니다

### 2-3. 예산

- 골격 + 영역 합계 **3,000줄** 안에서 읽습니다
- 넘으면 큰 파일부터 함수·클래스 시그니처와 모듈 상단 주석만 훑고 (`grep -n "^def \|^class "` 류), 본문은 다음 작업과 직접 닿는 부분만 읽습니다
- 데이터·실험 산출물·아카이브·테스트·생성 코드는 읽지 않습니다. 테스트는 다음 작업이 테스트 자체일 때만

## 3단계: 출력

```
## 프로젝트
한 줄 요약 · 기술 스택 · 현재 단계

## 현재 상태
SESSION.md 기준 진행 상황과 다음 작업 (원문 요약, 추측 금지)

## 코드 파악
- 실행 흐름: 진입점 → … → 출력 (읽은 골격 파일 기준)
- 핵심 모듈: 파일 | 역할 | 주요 함수·클래스 (읽은 것만)
- 다음 작업 관련 모듈: 어디를 어떻게 건드리게 되는지
- 문서·코드 불일치: 없으면 "없음"

## 다음 작업 제안
1~3개. 큰 변경은 계획 먼저
```

"코드 파악" 절이 빠진 출력은 미완료입니다. 읽지 않은 파일의 동작을 아는 것처럼 쓰지 않습니다. 읽은 범위 밖은 "미확인"으로 둡니다.

## 에러 처리

- 파일 일부 없음: 사용 가능한 정보로 요약하고 없는 파일을 불일치로 보고
- 작업 관리 도구(MCP) 연결 실패: SESSION.md 정보로 대체
